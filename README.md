# Практична робота

### Обране завдання
Перевірка числа Армстронга.

### Опис програми
Програма дозволяє користувачу ввести число та перевіряє, чи є воно числом Армстронга.

Число Армстронга — це число, яке дорівнює сумі своїх цифр, піднесених до степеня кількості цифр.

### Приклад

153 = 1³ + 5³ + 3³ = 153

Тому число 153 є числом Армстронга.

---

## Приклад роботи програми

```text
Enter number: 153
153 is an Armstrong number
```

```text
Enter number: 125
125 is NOT an Armstrong number
```
